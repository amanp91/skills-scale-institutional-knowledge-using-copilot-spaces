# OctoAcme Project Management Docs

## Overview

OctoAcme follows a structured project management methodology that emphasizes clear communication, risk management, and continuous improvement. Our processes cover the complete project lifecycle from initiation through retrospectives.

## Project Management Processes

OctoAcme's project management approach is built on the following core phases:

- **Initiation**: Validate business needs, align stakeholders, and create a lightweight plan with clear success metrics and timelines
- **Planning**: Break work into shippable increments, identify dependencies, define acceptance criteria, and align timelines and responsibilities
- **Execution & Tracking**: Implement work through daily standups, weekly syncs, and sprint-based iterations while maintaining quality through testing and code reviews
- **Risk & Communication**: Identify and manage risks proactively, maintain a risk register, and ensure transparent stakeholder communication through regular updates
- **Release & Deployment**: Execute controlled releases with pre-release requirements, smoke tests, and documented rollback plans
- **Retrospective & Improvement**: Capture learnings after each sprint or milestone and convert them into actionable improvements

### Key Characteristics

- **Customer-first**: Prioritize customer value and usability in all decisions
- **Iterative delivery**: Deliver small, testable increments regularly
- **Clear ownership**: Each project has a named Project Manager and Product Lead
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback, learning, and continuous improvement

### Core Roles

- **Project Manager (PM)**: Coordinates delivery, manages schedules, risks, and communications
- **Product Manager (PdM)**: Defines outcomes, prioritizes backlog, and measures success
- **Developers**: Implement features, collaborate on design and testability, maintain code quality
- **QA/Testing**: Validate quality and acceptance criteria

### Communication Cadence

- Weekly sync between PM and PdM
- Twice-weekly standups for delivery teams (or as agreed)
- Monthly stakeholder updates
- Ad-hoc escalations as needed
